# Porting this stage

This Unity project is a lossless export of one Aether Gazer stage, built for re-implementing it in another renderer (the target is a WebGPU engine). It is generated by `agtools/stage_unity.py` and is not hand-tuned: every value comes from the game's data, and the render logic comes from the game's own decompiled pipeline code.

## What is where

| Path | Contents |
| --- | --- |
| `Assets/**/<CODE>.unity`, `Assets/AGScenes/*.unity` | The scene. Prefab stages (the modifier-mode spaces) get a generated scene per prefab. |
| `Assets/**/*.mat` | The game's materials, unchanged: every property value and keyword as shipped. |
| `.shader` files (e.g. `Assets/Packages/com.p08.render/...`) | The game's shaders, decompiled from D3D11 bytecode. See "Shaders" below. |
| `Assets/**/*.asset` (Texture2D/Cubemap) | The textures' exact GPU data (BC1/3/5/6H/7, RGBAHalf, ...), HDR intact. `../_png_textures/` holds 8-bit previews only. |
| `Assets/Scripts/**` | The game's MonoBehaviours, rebuilt with their real serialized fields. The data is complete; the game's logic is not included. |
| `Assets/AGTools/` | The render pipeline stand-in, a port of the game's decompiled pipeline. `AGSimPipeline.cs` and `AGVolumes.cs` are the executable spec of scene data → shader inputs. |
| `ag_render_manifest.json` | Per scene: every rendering component (all fields), the volume profiles, lights and probes, a shader/keyword census, and the exact global uniforms and keywords fed to the shaders. Each `guid` has an `assetPath` next to it. |
| `AG_reference/pipeline/` | The game's pipeline assets: 53 pipeline shaders, 16 compute shaders (DXBC, disassembly, cbuffer layouts), feature settings, the bloom kernel, the SMAA and LTC tables. |
| `AG_reference/stage_components.json` | This stage's rendering components as read from the bundles (a cross-check for the manifest). |
| `../ag_stage.json` | The export record: bundles, scenes, roots switched on, and renderers disabled for having no material. |

## Shaders

The shaders are bit-exact HLSL. A DXBC register is typeless, so the temporaries are `uint4` holding raw bits, and each instruction reads its operands in its own type (`asfloat`/`asint`/`uint`). Comparisons produce `0xFFFFFFFF`/0. Every keyword variant is present. Porting to WGSL can follow the same model: `vec4<u32>` temps with `bitcast`.

## How the game renders a stage (what `AGTools` reproduces)

The live pipeline is `UnityEngine.Rendering.Replica` / `ReplicaExt`, which is URP-derived and volume-based. Colour space is linear. `GraphicsSettings.lightsUseLinearIntensity = false`, so a light's colour is `(colour × intensity)` converted gamma → linear.

- **Values:**
  - `SceneSetting.Update` writes the scene's fields into the volume defaults: `EnvironmentSetting`, `CharacterEnvironmentSetting` and `PostProcessSetting`.
  - Volume profiles override individual parameters (`m_OverrideState`), blended by weight in priority order.
  - The pipeline reads only the resolved stack. `AGVolumes.cs` resolves it the same way.
- **Colours:** the game uses `SetGlobalColor` (Unity converts gamma → linear) for fog, tint, `SimMainLightColor` and probe lighting, and `SetGlobalVector` (no conversion) for everything else. Mirror these exactly.
- **Main light:** the brightest visible directional light.
  - `SimMainLightDir = −forward`.
  - `SimMainLightColor = finalColor`.
  - `_MainLightPosition = forward` (w = 0), `_MainLightColor = finalColor`.
- **Additional lights, Forward+ (`PLUS_LIGHTING`, always on):**
  - Per light (up to 255), as in `LightInfo`:
    - position `(p, 1)` (directional lights: `(−forward, 0)`);
    - `finalColor`;
    - attenuation `(1/max(r², 1e−4), −r²/(0.64r² − r²), spotZ, spotW)` (points: z, w = 0, 1);
    - spot direction `(forward, 1/m_ShapeRadius)`;
    - extras `(volumetricDimmer, dummy, areaW/2, areaH/2)`;
    - the type (`m_ExtensionType` if set, else the Unity type);
    - the layer mask as raw bits;
    - a world-to-light matrix.
  - Lights are binned in screen tiles and URP-style depth bins, with a header word `min | max << 16` followed by bitmask words. The stand-in uses one bin holding every light, which shades identically. The shader also tests `unity_RenderingLayer & mask`.
  - `_LtcData` is a 64×64 RGBAHalf area-light LUT (`AG_reference/pipeline/textures/LTC_LUT_64x64_RGBAHalf.raw`).
  - The legacy `SIM_ADDITIONAL_LIGHT` path is only enabled at runtime by gameplay (`dynamicLightingEnabled`).
- **Ambient:** Unity's `RenderSettings.ambientProbe` of a trilight.
  - The colours are the scene RenderSettings ambient, or the environment's sky/equator/ground when both `sceneLightProbe` and `setLightProbe` are set, converted to linear first.
  - The raw coefficients are packed as `SHA = (c3, c1, c2, c0 − c6)`, `SHB = (c4, c5, 3·c6, c7)`, `SHC = (c8, 1)` → `_Replica_SH*`.
  - `_AcceptLightProbe` = `CharacterEnvironmentSetting.acceptLightProbe` (← `_sceneLightProbe`). At 0, surfaces get flat white ambient (`_CustomLightmap` defaults to white).
- **Reflection:**
  - Only when the environment has a `bakeReflectionTex`: `sim_EnvCube`, `sim_EnvCubeScale = bakeReflectionScale`.
  - Box projection from the reflection probe under `SceneSetting`: `sim_EnvCube_BoxMin/BoxMax`, `sim_EnvCube_ProbePosition = (position, 1/(½·|max − min|))`.
- **Fog:**
  - `sim_FogParams = (−1/(end − start), end/(end − start), height, gradient)`.
  - Colours via `SetGlobalColor`; zero when fog is off.
  - Keyword `sim_FOG_LINEAR`.
  - Dynamic fog: `sim_DYN_FOG_LINEAR`/`EXP`/`EXP_SQ`.
- **Other globals:**
  - Tint = `EnvironmentSetting.tint`, with a near-black tint treated as white.
  - `_SubtractiveShadowColor = linear(realtimeShadowColor)`.
  - `sim_Time = (t − floor t, floor t, 0, 0)`.
  - `sim_VertexAmbientScale`, shadow scatter.
- **Shadows:** cascaded, through each material's `SHADOWCASTER` pass.
  - Settings from `CascadeShadowSetting`.
  - Reversed-Z with a compare sampler, URP receiver matrices.
- **Post:**
  - **Bloom** (`BloomPass`) runs when `PostProcessSetting.contrast > 0`. `_Params = (0.77, 100, threshold, threshold × 0.5)`, with the threshold used as authored.
  - **Final:**
    - `tonemapping` comes from SceneSetting; exposure and contrast from `PostProcessSetting`.
    - With `ColorAdjustments.mode == 1`, ACES is used with exposure = 2^postExposure.
    - invert/grayness/darkness → `EXTRA_POSTEFFECT`; FXAA from `Antialiasing`.
    - Vignette and radial blur come only from a camera component that stages don't have.

`ag_render_manifest.json` → `shaderGlobals` / `shaderKeywords` records all of these for each scene. A port can upload them verbatim and compare its output with Unity.

## Not reproduced in the Unity stand-in: port from the references

| Effect | Scene parameters | Reference |
| --- | --- | --- |
| SSAO / GTAO | `SSAOSetting` | `shaders/Hidden/SimPipeline/ScreenSpaceAmbientOcclusion.shader`, `settings/*ScreenSpaceAmbientOcclusionFeature.json`. The stand-in feeds white and zero. |
| Volumetric lighting and fog | `VolumetricLightingSetting`, `LocalVolumetricFog` | `compute/VolumetricFog*`, `compute/VolumetricLighting*`, `compute/GenerateMaxZ`, `shaders/Hidden/Replica/Volumetric/Final.shader` |
| Light cookies | lights + `ReplicaAdditionalLightData` | `settings/*LightCookieFeature.json`. The stand-in sends no cookies. |
| Colour grading LUT | `ColorAdjustments`, `LiftGammaGain`, `ShadowsMidtonesHighlights`, `WhiteBalance` | `shaders/Hidden/RenderPipeline/Lut.shader`. The stand-in uses the scene LUT only. |
| Character and regional shadows | `SimMainLight` fields, `SIM_REGIONAL_SHADOW` | `shaders/Hidden/SimPipeline/CharacterShadow*.shader`, `DecalShadow.shader` |
| Planar / PPR reflection | `MirrorReflection*`, PPR | `compute/PixelProjectReflection`, `shaders/Hidden/PPR/PlaneID.shader` |

TAA is deliberately left out. The decompiled source of the whole pipeline (3,067 methods) is in the exporter's `AG_cache/re/decomp_all`.

## Gotchas

- Some stages save their root object inactive (the game enables it on load); the export switches it on. Renderers whose material slots are all empty are disabled, because a player build draws nothing for them. Both are listed in `../ag_stage.json`.
- The modifier-mode spaces are inner scenes (`_innerScene = 1`) that the game spawns into a battle: no fog, mostly effect shaders.
- Skybox domes are ordinary huge meshes (e.g. `sky_01`); there is no Unity skybox.
- "Combined Mesh (root: scene)" meshes are static-batched and already in world space.
- Home scenes have no camera in the data (the game places it in code); `Assets/AGTools/Resources/ag_viewpoints.json` holds viewpoints matched to the game's pictures.
